# J.A.R.V.I.S (web)

흰 `(error)` 화면으로 위장해 있다가, **박수 두 번**에 파란 파티클 원자 화면으로 전환되는 음성 비서입니다.
부품표·계산·도식·3D 모델(하이브리드 로봇팔 v0.1 포함)을 화면 좌우 패널에 띄웁니다.

## GitHub Pages에 올리기
1. GitHub에서 새 저장소를 만듭니다 (예: `jarvis`, Public).
2. **Add file → Upload files** 로 이 폴더의 파일 4개(`index.html`, `arm.json`, `arm.bin`, `.nojekyll`)를 올리고 Commit 합니다.
3. **Settings → Pages → Build and deployment**에서 Source를 **Deploy from a branch**, Branch를 **main / (root)** 로 저장합니다.
4. 1~2분 뒤 `https://<아이디>.github.io/jarvis/` 에서 열립니다.

## 처음 쓸 때
1. 페이지를 열면 흰 화면에 `(error)`만 보입니다.
2. **화면을 한 번 탭**해서 마이크를 켭니다. 브라우저가 마이크 권한을 물으면 허용하세요.
   - 아이폰과 대부분의 브라우저는 소리를 다루기 전에 탭을 한 번 요구합니다. PC Chrome에서 권한을 한 번 허용해 두면 다음부터는 탭 없이 바로 대기할 수도 있습니다.
3. **박수 두 번** → 화면이 전환되며 "Hello Jeongwoo, what are we working on today?"
4. 처음에는 설정 창이 뜹니다. **API 키**를 넣고 SAVE 하세요.
   - **Gemini (무료)**: https://aistudio.google.com/apikey 에서 Google 계정으로 발급. 하루 사용 횟수 제한이 있습니다. 모델은 비워 두면 자동으로 고릅니다.
   - **Claude (유료)**: https://console.anthropic.com/settings/keys
   - 키는 그 기기의 브라우저에만 저장되고 GitHub에는 올라가지 않습니다.
5. 그다음부터는 그냥 말하면 됩니다. 답을 들은 뒤 다시 자동으로 듣습니다.
6. "잘가", "대기", "goodbye" 또는 45초 동안 말이 없으면 다시 흰 `(error)` 화면으로 돌아갑니다.

## 인터넷 · 날씨 · 기억
- **웹 검색**: 뉴스, 최신 정보, 다른 도시 날씨 등을 물으면 AI가 직접 검색합니다. 오른쪽에 **출처 링크** 카드가 뜹니다.
  - Gemini: Google 검색 사용 (매달 5,000회 무료, 이후 유료)
  - Claude: 웹 검색 사용 시 검색 1,000회당 $10 추가
  - SET에서 끌 수 있습니다.
- **날씨**: "오늘 날씨 어때?" → 휴대폰 위치로 실시간 날씨(Open-Meteo, 무료)를 가져와 패널에 표시합니다. 처음에 위치 권한을 물어봅니다. 권한을 주지 않으려면 SET의 **기본 위치**에 도시를 적어 두세요.
- **기억**: 대화 중 알게 된 내 정보(선호, 프로젝트, 결정, 일정 등)를 스스로 저장하고 다음 대화에 활용합니다.
  - "이거 기억해줘", "그거 잊어줘"라고 직접 말해도 됩니다.
  - 저장된 기억은 **SET → MEMORY**에서 보고 하나씩 지울 수 있습니다.
  - 비밀번호, 카드·계좌·주민번호 같은 정보는 저장하지 않습니다.
  - 기억은 그 기기의 브라우저에만 저장됩니다. 다른 기기로 옮기려면 MEMORY의 **복사(백업)** → 다른 기기에서 **붙여넣기(복원)**.
  - 6시간 안에 다시 깨우면 직전 대화를 이어서 합니다.

## 문제 해결
- **박수가 안 잡힘**: 주소 끝에 `#debug`를 붙여 열면 왼쪽 아래에 마이크 레벨이 보입니다. 박수 칠 때 `peak` 값이 `clap` 값보다 커야 합니다. SET에서 박수 감도를 **높음**으로 바꾸세요.
- **화면이 꺼지면 박수를 못 듣습니다**: 대기 중 화면이 켜져 있도록 요청하지만, 지원하지 않는 기기는 자동 잠금 시간을 늘려 주세요.
- **음성 인식이 안 됨**: 아이폰은 설정 → Siri에서 받아쓰기·Siri가 켜져 있어야 할 수 있습니다. 안 되면 TALK 버튼이나 키보드 입력을 쓰세요.
- **"사용 한도에 도달했습니다"**: Gemini 무료 한도를 다 쓴 것입니다. 다음 날 초기화되거나, Claude 키를 쓰세요.
